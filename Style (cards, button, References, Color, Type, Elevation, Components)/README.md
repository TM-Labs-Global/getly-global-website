## Brand/content guardrails applied
- Cairo typography
- Getly Blue #0069FF and Getly Navy #0F184C
- No "send" / "transfer" language
- No USDC/stablecoin references
- Travel-first rather than bank-first positioning
- Insurance and Government Services omitted
- Fees are shown only as the supplied "$0 card issuance fee*" claim; all other fee amounts remain uninvented
